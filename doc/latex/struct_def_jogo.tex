\doxysubsection{Detailed Description}
Estrutura principal que armazena todas as regras e configurações de uma paciência. 

Esta estrutura é construída pelo parser (\doxylink{parser_8c_source}{parser.\+c}) ao ler o ficheiro {\ttfamily .paciencia} Contém o "{}\+ADN"{} completo do jogo, incluindo os arrays dinâmicos com todas as regras válidas.
